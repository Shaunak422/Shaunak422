## 🔬 Featured Projects

### ⚡ [Modular Multi-Strategy RAG Engine](https://github.com/Shaunak422/RAG)
> Production-grade Retrieval-Augmented Generation framework comparing and benchmarking **6 RAG paradigms** (Naive, Cross-Encoder Reranker, CRAG, Multi-Hop, Graph RAG, and Agentic Planning).
- Engineered a two-stage retrieval pipeline using **LangChain LCEL**, BGE embeddings with MMR diversity search, cross-encoder precision reranking, SHA-256 deduplication, and self-correcting query rewrite loops.

### 🖼️ [CNN Image Classification & Hyperparameter Ablation](https://github.com/Shaunak422)
> Designed a 3-block Deep CNN (Conv2D–MaxPooling–Dropout) in **TensorFlow/Keras** classifying CIFAR-10 images.
- Reached **80.5% validation accuracy** through systematic ablation studies of network depth, kernel sizes ($3\times3$), optimizers (Adam vs. SGD), and batch sizes across 10+ training runs.

### 🩺 [Diabetes Prediction using Machine Learning](https://github.com/Shaunak422)
> Predictive modeling and decision support system built on the Pima Indians Diabetes dataset using **Python**, **Scikit-learn**, and **Pandas**.
- Achieved **75% classification accuracy** by systematically benchmarking Gini vs. Entropy split criteria and tuning hyperparameters across 9 Decision Tree configurations.
- Conducted confusion-matrix error diagnosis, evaluating precision, recall, and decision boundaries for reliable decision support.

### 🤖 [Automated Service Delivery & Workflow Visualization](https://github.com/Shaunak422)
> Designed full-stack integrations using **React**, **Node.js**, **Express**, and **MySQL** for automated service interactions and visual workflow rendering.
- Integrated a **Dialogflow chatbot** with location-based services via the Google Maps API to automate customer queries in real time.
- Implemented the **Dagre graph layout algorithm** within **React Flow** to automate structured workflow diagrams.
